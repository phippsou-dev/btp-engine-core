**Source de vérité canonique du moteur d'analyse BTP MyHome**

## Vue d'ensemble

`btp-engine-core` est le moteur backend d'analyse de dossiers de construction (BTP). Il transforme des PDF/ZIP de projets en inventaires structurés, extractions de problèmes, tâches candidates avec préconisations expert et mappings DST.

**Mode de fonctionnement strict** :
- 🚫 **Aucun appel GPT/OpenAI/Gemini/Vision**
- 🚫 **Aucune écriture en base de données**
- 🚫 **Aucun push DST**
- 🚫 **Aucun accès PROD**
- ✅ **100% local, déterministe et testable**
- ✅ **Guardrails fail-closed obligatoires**
